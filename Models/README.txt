Thư mục Models
==============

- house-price-model.zip: Tự động tạo khi chạy Backend lần đầu (ML.NET mock training).
- llama-model.gguf: Đặt file LLM local của bạn tại đây, hoặc sửa đường dẫn trong appsettings.json (Llama:ModelPath).

Ví dụ model nhẹ để test: TinyLlama, Phi-2, Qwen2.5-0.5B-Instruct (định dạng .gguf).
